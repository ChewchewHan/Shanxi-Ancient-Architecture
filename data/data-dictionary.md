# 数据字段说明

| 字段 | 含义 | 注意事项 |
|---|---|---|
| id | 本仓库稳定编号 | 新增记录时不重复使用已有编号 |
| city | 所属地级市 | 按原始 KML 文件夹整理 |
| name | 原始地点名称 | 保留名称中的暂停开放、维修等提示 |
| longitude / latitude | 原始 KML 坐标 | 来源 KML 声明 CGCS2000；不是已转换的 WGS84/GCJ-02/BD-09 |
| coordinate_reference | 坐标参考说明 | 未经专业转换不用于精准测绘 |
| source_file / source_url | 原始来源 | 便于追溯 |
| dating_status | 断代核实状态 | 初始均为待核实；只有附有来源后才更新 |
| construction_period | 现存某一具体建筑/构件建造年代 | 必须注明对应建筑本体 |
| founding_period | 寺院/庙宇创建年代 | 不得与现存殿堂建造年代混淆 |
| heritage_level | 文物保护级别 | 需有官方名录来源 |
| access_hint | 原文件中的开放提示 | 不是实时状态 |
| access_checked_at | 开放状态最后核查日 | 过期信息必须重新确认 |
| source_confidence | 证据等级 | A、B、C 及理由见下 |
| google_maps_search_url | Google Maps 搜索入口 | 坐标可能存在坐标系偏移，需抽样核对 |
| notes | 补充说明 | 明示不确定性 |

## 核实等级

- **A**：正式文物调查、保护档案、碑刻题记、官方文物单位资料或专业机构研究能直接支持核心断代。
- **B**：多个可靠来源相互印证，或有政府/博物馆资料，但仍缺少构件级正式报告。
- **C**：来自地图标记、名称线索、游客资料或未经交叉核对的信息。

等级不是文物等级。A/B/C 表示资料证据成熟度，不代表建筑价值高低。

## 记录状态建议

- `待核实`：只知道地点和坐标。
- `部分核实`：有可靠年代，但构件、维修史或参观权限未查清。
- `已核实`：主要断代、对象范围和来源均可追溯。
- `暂不可参观`：必须附带官方公告或近期可靠核查记录及日期。

## 编辑规则

1. 所有年代应明确对象：寺院、殿堂、塔、壁画、彩塑、碑刻不能混为一谈。
2. 使用公历年份时最好同时保留年号与朝代。
3. 有争议时列出各说法与出处，不以单一旅游网站定论。
4. 不删除原始点位；确认为重复或错误时保留变更说明。
5. 开放状态属于动态信息，历史档案不可代替出发前核验。
