# 數據字段說明

| 字段 | 含義 | 注意事項 |
|---|---|---|
| id | 本倉庫穩定編號 | 新增記錄時不重複使用已有編號 |
| city | 所屬地級市 | 按原始 KML 文件夾整理 |
| name | 原始地點名稱 | 保留名稱中的暫停開放、維修等提示 |
| longitude / latitude | 原始 KML 座標 | 影片位置資訊轉為 Google Earth KML；原始座標基準與轉換參數待核實 |
| coordinate_reference | 座標參考說明 | 未經專業轉換不用於精準測繪 |
| source_file / source_url | 原始來源 | 便於追溯 |
| dating_status | 斷代覈實狀態 | 初始均爲待覈實；只有附有來源後才更新 |
| construction_period | 現存某一具體建築/構件建造年代 | 必須註明對應建築本體 |
| founding_period | 寺院/廟宇創建年代 | 不得與現存殿堂建造年代混淆 |
| heritage_level | 文物保護級別 | 需有官方名錄來源 |
| access_hint | 原文件中的開放提示 | 不是實時狀態 |
| access_checked_at | 開放狀態最後覈查日 | 過期信息必須重新確認 |
| source_confidence | 證據等級 | A、B、C 及理由見下 |
| google_maps_search_url | Google Maps 搜索入口 | 座標可能存在座標系偏移，需抽樣覈對 |
| notes | 補充說明 | 明示不確定性 |

## 覈實等級

- **A**：正式文物調查、保護檔案、碑刻題記、官方文物單位資料或專業機構研究能直接支持核心斷代。
- **B**：多個可靠來源相互印證，或有政府/博物館資料，但仍缺少構件級正式報告。
- **C**：來自地圖標記、名稱線索、遊客資料或未經交叉覈對的信息。

等級不是文物等級。A/B/C 表示資料證據成熟度，不代表建築價值高低。

## 記錄狀態建議

- `待覈實`：只知道地點和座標。
- `部分覈實`：有可靠年代，但構件、維修史或參觀權限未查清。
- `已覈實`：主要斷代、對象範圍和來源均可追溯。
- `暫不可參觀`：必須附帶官方公告或近期可靠覈查記錄及日期。

## 編輯規則

1. 所有年代應明確對象：寺院、殿堂、塔、壁畫、彩塑、碑刻不能混爲一談。
2. 使用公曆年份時最好同時保留年號與朝代。
3. 有爭議時列出各說法與出處，不以單一旅遊網站定論。
4. 不刪除原始點位；確認爲重複或錯誤時保留變更說明。
5. 開放狀態屬於動態信息，歷史檔案不可代替出發前核驗。
