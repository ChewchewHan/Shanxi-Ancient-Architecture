# 浑源悬空寺｜崖壁木构建筑群

- 行政区：大同市浑源县恒山金龙峡
- 传统始建年代：北魏太和十五年（491）；不同官方资料有“北魏后期”或491年的不同表述。
- 现存木构：恒山风景名胜区管理中心资料称，现存木构建筑部分主要为明清遗构，历代均有重修。
- 核实等级：A（景区管理中心、浑源县政府资料）
- 地图：全量 KML 搜索「悬空寺」。

## 历史断代必须分层

悬空寺的传统始建时间为北魏太和十五年（491），但这不意味着今天看到的全部木构都来自北魏。恒山风景名胜区管理中心的古建档案记载，寺院历经唐、宋、金、元、明、清重修，现存木构建筑部分为明清遗构。浑源县政府资料也指出寺院始建于北魏后期，现存布局与殿阁经过历代修缮。

因此应分开记录：
1. 北魏时期寺院/道坛沿革；
2. 唐、宋、金、元等历代维修；
3. 明清时期现存木构遗存；
4. 1970年代以来的修缮、加固和环境治理。

## 建筑结构观察

- 寺院依崖壁凿洞、插梁为基，部分梁体借岩体暗托。
- 殿阁沿峭壁分层布置，以栈道、回廊和楼梯连接。
- 观察梁柱节点、插梁、悬臂木梁、栈道和崖体之间的关系。
- 寺内有佛、道、儒三教合祀空间，建筑组合与宗教空间使用相互关联。

## 保护与登临

悬空寺是结构风险和游客人流都需重点管理的文物。2026年4月，相关报道介绍在梁、柱、栈道等关键节点布设光纤传感网络，进行结构振动监测。同年4月起实施更严格的登临名额管理。

出发前应重新确认当日登临配额、预约时间、票种、限流及临时关闭情况；不要把“景区入园票”当成“登临票”。不进入封闭区域，不触碰结构构件。

## 实地观察顺序

1. 先从峡谷对岸观察寺院总体选址和崖壁关系。
2. 登临时观察殿阁之间的连接、栈道和悬臂构件。
3. 区分明清遗构与历代重修部分，不凭外观直接断代。
4. 注意现场文物保护标识，避免长时间停留造成拥堵。
