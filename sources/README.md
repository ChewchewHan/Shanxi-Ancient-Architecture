# 资料来源与研究规范

## 来源优先级

1. 国家文物局、文化和旅游部、国家级/省级文物主管部门、文物保护单位管理机构。
2. 市县人民政府、文旅局、博物馆和考古/文博专业机构。
3. 正式发表的建筑史、考古、文物保护研究论文与正式调查报告。
4. 高校和专业研究机构发布的教学/研究资料。
5. 可靠媒体的专题报道，仅用于线索与补充，不单独承担关键断代。

旅游平台、用户地图、百科和社交媒体可用于发现地点，但不应成为唯一断代证据。

## 来源审查规则

- 记录标题、发布机构、日期、URL、核查日期。
- 尽可能引用原始政府/博物馆/高校页面，而非转载。
- 关键断代至少有一条足以支持对象和年代的来源；争议年代并列呈现。
- 动态开放、票务、预约信息须记录“核查日期”，原则上出发前7天重新核对。
- 图片、图纸、扫描资料应遵守版权；优先链接原页面，不复制整篇文章。
