# 用本倉庫規劃旅行

以後規劃山西古建旅行時，可先給 ChatGPT 本倉庫地址：

https://github.com/ChewchewHan/Shanxi-Ancient-Architecture

請明確要求讀取當前 main 分支中的：
- `data/sites.json` 或 `data/sites.csv`：全量地點與座標；
- `places/`：重點建築檔案；
- `maps/`：KML 地圖；
- `itineraries/`：已有路線方案；
- `sources/`：斷代來源與核實方法。

## 規劃時仍須實時查驗的資料

GitHub 是歷史知識和座標底庫，不會自動知道：
- 今天是否開放、臨時閉館或施工；
- 預約、餘票、票價、景區接駁；
- 道路施工、天氣、山路限制；
- 酒店與租車實時價格。

規劃時應對這些動態事項另行搜尋官方/景區來源，標明核查日期和連結。

## 推薦提問模板

“請讀取 Shanxi-Ancient-Architecture 倉庫 main 分支，按我這次的出發日期、天數、出發地、交通方式與興趣重新規劃。優先選資料中斷代有可靠來源、現存構件價值高且實際可參觀的地點。把待考點列為備選，不要把未核實年代寫成事實。逐日給出路線、住宿區域、駕駛量、景區開放核查、預約和票務官方連結。”

## 重要邊界

- 資料庫不能替代現場文物管理要求。
- 訂票時最後的實名認證、付款和退改確認由旅行者完成。
- 任何未核實的景點狀態不得寫成“確定開放”。
