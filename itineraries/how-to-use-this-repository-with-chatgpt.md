# 用本仓库规划旅行

以后规划山西古建旅行时，可先给 ChatGPT 本仓库地址：

https://github.com/ChewchewHan/Shanxi-Ancient-Architecture

请明确要求读取当前 main 分支中的：
- `data/sites.json` 或 `data/sites.csv`：全量地点与坐标；
- `places/`：重点建筑档案；
- `maps/`：KML 地图；
- `itineraries/`：已有路线方案；
- `sources/`：断代来源与核实方法。

## 规划时仍须实时查验的资料

GitHub 是历史知识和坐标底库，不会自动知道：
- 今天是否开放、临时闭馆或施工；
- 预约、余票、票价、景区接驳；
- 道路施工、天气、山路限制；
- 酒店与租车实时价格。

规划时应对这些动态事项另行搜索官方/景区来源，标明核查日期和链接。

## 推荐提问模板

“请读取 Shanxi-Ancient-Architecture 仓库 main 分支，按我这次的出发日期、天数、出发地、交通方式与兴趣重新规划。优先选资料中断代有可靠来源、现存构件价值高且实际可参观的地点。把待考点列为备选，不要把未核实年代写成事实。逐日给出路线、住宿区域、驾驶量、景区开放核查、预约和票务官方链接。”

## 重要边界

- 资料库不能替代现场文物管理要求。
- 订票时最后的实名认证、付款和退改确认由旅行者完成。
- 任何未核实的景点状态不得写成“确定开放”。
